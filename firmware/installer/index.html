Waveshare Relays for Signal K

Firmware for the Waveshare ESP32-S3-ETH-8DI-8RO relay board, for use with the signalk-waveshare-relays plugin.

Your browser can't install firmware. Use Chrome or Edge on a desktop or laptop. The installer needs a secure (https) page.
Firmware version {{VERSION}}
Installing erases the board, including any admin password stored on it. To update a board that already runs this firmware and keep its settings, use the OTA method below.

New board

  1. Connect the board's USB-C port to this computer.
  2. Click Connect and install and pick the board's serial port. If no port appears, hold the BOOT button, press and release RESET, then release BOOT and try again.
  3. When the installer finishes it offers to set up Wi-Fi. Enter your network, or skip it and use Ethernet. If you skip it, the board also starts a Waveshare Relays Setup access point after 90 seconds with no network.
  4. Install the Waveshare Relays plugin from the Signal K App Store. The board is listed at the top of the plugin's settings. Add it and set an admin password.

Updating a board

  1. Download waveshare-relays-{{VERSION}}.ota.bin from the release page.
  2. Open the board's web page, for example http://waveshare-relays-xxxxxx.local, and log in as admin with the password set in the plugin.
  3. Upload the file under OTA Update. The board restarts with the new version and keeps its network settings and admin password.
